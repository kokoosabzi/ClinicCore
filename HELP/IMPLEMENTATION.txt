# ClinicCore — دستورالعمل نصب و توسعه محلی

## نصب در Windows

از ریشه مخزن:
```bat
setup.bat
```

این اسکریپت محیط مجازی `.venv`، وابستگی‌های Python، تنظیمات امن نصب تازه، دیتابیس SQLite و حساب مدیر اولیه را آماده می‌کند.

## اجرا و توقف

```bat
start.bat
stop.bat
```

برنامه در آدرس http://127.0.0.1:8000 در دسترس خواهد بود.

## دستورات توسعه

پس از فعال‌سازی محیط مجازی:
```powershell
.\.venv\Scripts\Activate.ps1
python -m compileall app tests main.py alembic scripts
python -m pytest -q
python -m alembic upgrade head
python scripts/seed_admin.py
```

## دیتابیس

در نسخه فعلی، SQLite تنها دیتابیس پشتیبانی‌شده است و فایل پیش‌فرض آن `data/cliniccore.db` است. برای تغییر ساختار دیتابیس فقط Migration جدید Alembic بسازید. فایل‌های دیتابیس موجود را حذف یا جایگزین نکنید.

## نکته امنیتی

در نصب تازه، `scripts/bootstrap_env.py` یک `SECRET_KEY` و رمز تصادفی مدیر تولید می‌کند. فایل `.env` خصوصی است و نباید commit شود. حساب مدیر در اولین ورود باید رمز را تغییر دهد.
