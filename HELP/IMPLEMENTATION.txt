# Implementation and Run Instructions

## 1. Install
\`\`\`bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
\`\`\`

## 2. Configure PostgreSQL
Create \`.env\`:

\`\`\`env
DATABASE_URL=postgresql+psycopg://cliniccore:cliniccore@localhost:5432/cliniccore
SECRET_KEY=replace-with-a-long-random-secret
ADMIN_USERNAME=admin
ADMIN_PASSWORD=replace-with-a-strong-unique-password
\`\`\`

**Production requirement:** do not leave \`ADMIN_PASSWORD=admin\`. The fallback \`admin\` password is for development only. Set the production credentials before running the seed command.

## 3. Migrate database
\`\`\`bash
alembic upgrade head
\`\`\`

## 4. Create initial manager
\`\`\`bash
python scripts/seed_admin.py
\`\`\`

The seeded admin is forced to change the password on first login. If the fallback password is used, the seed script prints a security warning.

## 5. Run
\`\`\`bash
uvicorn app.main:app --reload
\`\`\`

## 6. Validate
\`\`\`bash
python -m pytest
\`\`\`
